## 3. 为什么不能给所有旧数字补“±标准差”

1. **原表口径未完全可追溯。** 投稿Protocol写十种子均值，但旧clean10基线导出明确seed=123，ACC取末十轮最大、公平指标取末十轮最小，三个指标可能来自不同轮。部分投稿数字与该导出相符，不能仅凭原文声明认定其为均值。
2. **后期十种子配方不同。** 后期F Flip为all_unprivileged，FedSA gain=4.5/norm_ratio=3；旧导出F Flip为invert，另一个旧FedSA三种子队列为gain=1.75/norm_ratio=2。不同配方不能共用SD或合并。
3. **五场景尚不能全部恢复同配方十种子。** 本次保留档案中，S-DFA/Sp-DFA的非AD2方法旧候选仍是单种子；后期这两场景只有AD2+恶意比例队列，不能借来补基线的重复数。
4. **展示名与实现名尚有疑点。** FedWA可能对应旧AdaAggRL导出，Cosine Similarity + Fairness Deviation及FairGuard→FLTrust的真实代码路径还需核验。本报告只作候选检索，不认证算法等价或组合顺序。
5. **零值和N/E须区分。** 低准确率不能成为隐藏已定义公平数值的理由；但原日志缺少测试集各组正例分母，不能把真实记录的0直接认定为未定义，也不能用N/E推断原始NaN。原表FairFed non-IID FedSA的71.90% ACC仍显示公平值，亦与正文统一80%隐藏规则不一致。
