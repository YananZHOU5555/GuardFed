## 3. 三类真实统计口径

**单种子：294格、98条件。** 来源是clean10保留记录seed123。脚本逐指标取末十轮ACC最大、AEOD/ASPD最小，并选择最后一条匹配记录；94/98条件不存在三个指标共同选中的一轮。它们不是十种子均值，不能计算跨seed SD。表内标注上标1，SD不可用；不填写0，不用轮间波动代替跨seed SD。

**十种子：180格、60条件。** 多数F-Flip/FedSA来源为Windows攻击计划。每seed三指标来自一个共同选轮，再跨123、456、789、1001、2024、3141、4242、5050、6060、7070十seed取mean与sampleSD（ddof=1）。F-Flip对FairFed/FairGuard/组合/GuardFed系列最小化AEOD+ASPD，对其他方法最大化；FedSA对FedAvg/FairFed最小化ACC，对其他方法最大化；并列取较后轮。这是按方法改变方向的历史test选轮，不能称为统一协议的无偏排名。

**三种子：6格、2条件。** FedWA展示行的FedSA列实际源方法为AdaAggRL，seed123/456/789；每seed在61–70轮最大化ACC−0.5(AEOD+ASPD)，并列取较早轮，然后计算mean±sampleSD。不是十种子。

部分选轮导出沿用了原终轮的valid_n/资格字段；本次没有把这些字段认作选中轮的分组分母证据。旧日志的AEOD实现为绝对TPR差，正文定义必须与之对齐。

## 5. 同终轮修正候选的用途与边界

同终轮候选从同一run的第70轮记录同时取三指标；n≥2时跨真实seed计算mean±sampleSD，n=1时展示单次值。它消除了历史逐指标/方法差异选轮造成的混合。它仍保留真实不同训练配方和样本数，并标明上述方法身份问题；不能称为全部10seed、完全统一配方或最终可提交的忠实基线对照。

例如，后期十种子F-Flip配方为all_unprivileged，旧单种子为invert；FedSA后期gain=4.5/norm_ratio=3、AdaAggRL三种子gain=1.75/norm_ratio=2。各列均使用自身真实记录，不借用另一队列的SD。终轮的“同checkpoint”指日志中同run同round记录一致，不代表已找回并核验所有历史模型二进制SHA；原日志也没有完整源码、数据与模型内容哈希，不能补称已验收这些身份。
