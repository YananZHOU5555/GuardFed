This directory contains source preparation only. It does **not** contain an accepted C11 closure or any generated C three-view table. The known adopted C1 receipt is pinned. The actual C-after1 eleven-result ROOT_ADOPTION_REVIEW and its external SHA must be supplied by root before the builder runs. No future path, receipt SHA, result or resource-readiness fact is invented.

The frozen target is C IID Benign, seeds 91001–91010, paired with the corresponding accepted Full900 records. Raw, native and shared_calibration each receive the same 10/9/6 panels. Full/minus_C and within-seed minus_C−Full differences use the unchanged original `evidence_v4.statistic/summarize` functions. ACC is percent, ΔACC is percentage points, and SD is sample SD (ddof=1). This will produce 27 rows / 81 mean±SD cells / 162 scalar statistics after adoption. Original `receipt_identity/normalized`, bridge canonicalization and U100 Full-reference normalization are reused. The native C table is checked against the root-accepted native single-scene source. Full weights are never reloaded or repacked and no threshold is refitted. [SCOPE_SOURCE_DIFF.patch](SCOPE_SOURCE_DIFF.patch) contains the complete U100→single-C statistics/verifier diff; [SOURCE_REUSE.md](SOURCE_REUSE.md) describes the join/build changes.
