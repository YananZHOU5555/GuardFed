# Hybrid private three-view identity bridge

Source-only bridge for the twelve **already root-adopted native** CosineFairnessHybrid checkpoints. Run the local metadata check with:

```powershell
python -B tmp/celeba_hybrid_three_view_bridge_20261011/bridge.py --check
```

`identity_record(id, checkpoint_sha256=...)` returns a private canonical record for the existing replay interfaces: original config, alpha, root/client/valid identity, result/job/model member pins, terminal native metrics and unmodified training provenance. It reads only small pinned JSON/source files; it never opens model, archive or array bytes. The model SHA is joined through the original member inventory, saved strict/offserver proof and root adoption, rather than rehashed here. Unknown IDs and a caller checkpoint mismatch are refused.

The frozen scope is Benign seeds 91002–91010 plus F Flip seeds 91001–91003, in the actual 1→9→12 root chain. Screen reuse4 and later observed completions are outside this bridge. No future100 inventory/jobs or new scientific acceptances are created.

`science_bindings(torch_module=..., pandas_module=...)` delegates directly to the accepted original bridge loader. Its 17 original functions include `rebuild_root`, root-only shared fitting, prediction and metric evaluation; their bodies and the frozen shared-threshold recipe are unchanged. The original core source is pinned for the caller's real `model_margins`/`fit_group_thresholds`/root sampling functions. This preparation constructs the function bindings without calling them. Native/raw retain **margin > 0**, shared retains **margin >= group threshold**, and future native replay retains **1e-12**. There is no new math implementation.

`INPUTS.json` records the actual paths/SHA of each original root, strict/offserver/member/receipt and compact artifact. The Hybrid `body.checked`, `common.accepted` and `runtime.functions` sources are pinned unchanged. Their GPU/Torch scientific paths are **not executed** by this CPU metadata bridge; the already accepted external strict proofs remain authoritative for the native artifacts. Original CUDA training provenance is retained, not replaced with a CPU runtime or a fake CUDA object. `CHECK.json` is a record-layer result, not a new saved-array/native replay acceptance or a cross-platform numerical-equivalence proof.

This adds only private accepted-ID selection and compact identity joins around the original metadata/science loader. The old900 inventory, original Hybrid sources, FL47 candidate and all old evidence remain unchanged. Original undefined Pearson handling remains in the original diagnostic writer/null sidecar only; this bridge neither normalizes diagnostics nor replaces nonfinite scientific metrics.

The F paths refer to existing read-only recovery metadata. Server model/output paths are separately recorded under `/workspace/guardfed_checks/celeba_hybrid_fullcoverage_v3_20261010/stage`; Windows/F paths must not be used as Linux model paths. Source/data/model rehashes, producer quiescence, fresh resources/volume, genuine native1e-12 replay and a root-authorized execution remain prerequisites for any future runtime gate. Nothing here dispatches, trains, forwards, fits, reads test predictions, chooses a new recipe, or completes Hybrid100.
